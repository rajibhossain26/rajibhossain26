## Hi, I'm Rajib 👋

**PhD candidate in Geography at the University of Georgia.** I use GIScience, remote sensing and GeoAI to study how built and natural environments shape people's health, and who is most exposed when disasters hit.

- 🌡️ Environmental exposures: urban heat, greenness and tree canopy, access to healthcare
- 🌀 Disaster resilience: hurricane impacts and evacuation equity
- 🛰️ Satellite and street-level imagery, spatial statistics, Google Earth Engine, Python
- 🧑‍🏫 GIS instructor at UGA (previously Florida State); former planning & GIS coordinator in Dhaka, Bangladesh
- 💬 Open to collaborations and roles in geospatial data science, environmental health and climate resilience. Connect on [LinkedIn](https://www.linkedin.com/in/hossainrajib).

### 🔬 Projects

| Project | What it does | Stack |
| --- | --- | --- |
| [**us-tree-canopy-change**](https://github.com/rajibhossain26/us-tree-canopy-change) | Four decades of US tree canopy change for all 3,100+ counties from 30 m USFS/NLCD rasters (~15 billion pixels a year), processed in GitHub Actions: Southeast gains, Western losses, Moran's I clusters. | Python · rasterio · GeoPandas · CI |
| [**georgia-health-atlas**](https://github.com/rajibhossain26/georgia-health-atlas) | Where chronic disease and social needs cluster across Georgia's 159 counties: CDC PLACES 2025 data in a SQL database, global and local Moran's I hot spots, maps and findings. | SQL · Python · Spatial statistics |
| [**healthcare-access**](https://github.com/rajibhossain26/healthcare-access) [![PyPI](https://img.shields.io/pypi/v/healthcare-access)](https://pypi.org/project/healthcare-access/) | Python package on PyPI (`pip install healthcare-access`) for spatial access to healthcare: 2SFCA, Enhanced, Gaussian, Modified and Three-step FCA, and gravity models, with OpenStreetMap drive times and equity metrics. Tested, with CI. | Python · NetworkX · OSMnx |
| [**urban-heat-equity**](https://github.com/rajibhossain26/urban-heat-equity) | Who lives in the hottest, least green neighborhoods? Landsat surface temperature and tree cover by census tract, joined to ACS data, with robust regression and Moran's I. | Earth Engine · Python · Census API |
| [**storm-canopy-change**](https://github.com/rajibhossain26/storm-canopy-change) | Hurricane canopy loss from Sentinel-2 with seasonal correction, county loss areas, and area-weighted accuracy assessment (Olofsson et al. 2014). | Earth Engine · Sentinel-2 · Python |
